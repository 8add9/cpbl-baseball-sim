# Career Mode v0.4 Design Specification

Source: `design/concepts/career-v4-dashboard-desktop.png`.

The home screen is a weekly planning dashboard. Preserve the dark navy, red and gold
CPBL numerical management system with crisp table rails and condensed statistics.

- Header: 生涯首頁、訓練中心、本週行程、數據紀錄、生涯歷史.
- Left: identity, age, archetype, team/status, contract, Trust, pending event.
- Center: dominant seven-day calendar, AP 4/4, activity/opponent/location/cost.
- Right: ratings, Potential, Fatigue, Form, next game, attainable goals.
- Primary actions: 安排訓練、進行下一場、模擬本週. Never Next PA on home.
- Required states: training XP planner, PA approach, post-game summary, season/offseason.

Desktop target is 1440x900; mobile 390x844 changes rails into tabs and keeps the weekly
decision above statistics. No sprites, 3D, animation, gacha, trades or Phase 2 systems.
